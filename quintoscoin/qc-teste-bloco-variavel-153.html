🔐 QuintosCoin — Passo 153

Teste de bloco RSA variável entre Chrome e Apps Script. O navegador gera 512 bytes de teste e o servidor os assina usando somente a chave pública de demonstração da RFC 9474. A assinatura é verificada no Chrome.

Este passo não cria uma ficha EMSA-PSS cegada. O objetivo é comprovar a assinatura remota de um bloco variável, antes do teste completo de cegamento.

O código não é salvo pelo navegador nem incluído no HTML publicado. Nunca o coloque no repositório.
